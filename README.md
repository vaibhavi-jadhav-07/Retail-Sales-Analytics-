# 🛒 Retail Sales Analytics Dashboard

## 📌 Project Overview

This project demonstrates end-to-end Retail Sales Analytics using **MySQL** and **Power BI**.

The project includes database creation, SQL business reports, data analysis, and an interactive dashboard.

---

## 🛠️ Tools Used

- MySQL
- Power BI
- SQL
- DAX

---

## 📊 Dashboard Features

- 💰 Total Revenue
- 📦 Total Orders
- 👥 Total Customers
- 🛒 Total Products
- 📈 Monthly Revenue Trend
- 📊 Revenue by Category
- 📍 Revenue by City
- 👤 Customer Analysis
- 🎛️ Interactive Slicers

---

## 📂 Dataset

- 500 Customers
- 100 Products
- 5,000 Orders
- 12,000+ Order Details
